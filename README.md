# ✈️ Travel Agency Management (C)

Console application written in **C** to manage a travel agency: trips, bookings and agency statistics. Data is kept in arrays in memory and pre-filled with sample (fictional) data.

## Features
**Trip management**
- List all trips, or only individual / group trips
- Add, delete and postpone a trip
- Book a trip and cancel a booking
- List bookings and the trips taken by a traveler (by passport number)
- Draw a random winner for a free trip

**Agency statistics**
- Total trips and distinct clients
- Most frequent traveler
- Most profitable individual and group trip, average revenue per trip
- Most / least visited destination country
- Months with the most / fewest requests
- Most frequent age group

## Build and run
```
gcc main.c -o travel_agency
./travel_agency
```
Or open `travel_agency.cbp` in Code::Blocks.
